# ✂️ BarberX — Барбершоп премиум-класса

> Современный, стильный и адаптивный сайт для барбершопа, созданный для привлечения клиентов и удобной записи на услуги.

![Status](https://img.shields.io/badge/status-active-success) ![Version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/license-MIT-green)

---

## 🚀 Возможности

| Функция | Описание |
|---------|----------|
| 📅 **Онлайн-запись** | Быстрый выбор услуг, мастеров и удобного времени |
| 🖼️ **Портфолио** | Демонстрация стрижек, бород и атмосферы заведения |
| 💰 **Прайс-лист** | Прозрачные цены на все виды услуг |
| 📍 **Контакты** | Удобное расположение, график работы и ссылки на соцсети |
| 📱 **Адаптивность** | Идеально на смартфонах, планшетах и ПК |

## 📦 Быстрый старт

### Клонирование

```bash
git clone https://github.com/your-username/siteBarber.git
cd siteBarber
```

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

### Сборка для продакшена

```bash
npm run build
```

## 🎨 Секции сайта

- **Hero** — главный экран с призывом к действию
- **Услуги** — полный прайс-лист с ценами
- **Мастера** — команда с рейтингами
- **Галерея** — портфолио работ с фильтрацией
- **Онлайн-запись** — пошаговая форма бронирования
- **Контакты** — адрес, телефон, соцсети
